# Legg til kundeleveranser

1. Åpne `/studio` på nettstedet og logg inn med din Sanity-konto. Kontoen må ha redigeringstilgang til prosjektet `urcqwilp`.
2. Velg **Kundeleveranser**, og opprett et nytt dokument.
3. Fyll inn prosjekttittel, godkjent kundenavn, leveringsår, tjenester, kort presentasjon og gjerne bilde med beskrivende alt-tekst.
4. Beskriv kundens behov, løsningen og konkrete leveranser. Ikke oppgi uverifiserte resultater som dokumenterte fakta.
5. Merk **Kunden har godkjent offentlig presentasjon og bildebruk** bare når tillatelse foreligger. Eventuelle resultater krever også **Resultatene er verifisert og kan publiseres**.
6. Trykk **Publish**. Prosjektet vises på `/prosjekter` ved neste oppdatering av innholdets hurtigbuffer (ca. ett minutt etter en ny sideforespørsel).

Utkast og prosjekter uten publiseringsgodkjenning vises ikke. Et prosjekt kan skjules ved å fjerne godkjenningen og publisere endringen, eller ved å avpublisere dokumentet.

Alle illustrasjonene under «Fra tjeneste til uttrykk» er originale konseptforslag, ikke utførte kundeoppdrag. Ingen fiktive kundecaser eller resultater er lagt til.

Studio-innlogging krever fungerende Sanity-tilgang og korrekt CORS for nettstedets offentlige origin. Oppretting, bildeopplasting og faktisk publisering må kontrolleres med eierens tilgang før produksjonsgodkjenning. Ingen kundedata er skrevet til Sanity under utviklingen.
